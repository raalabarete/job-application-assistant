## Statuses

`In Progress` · `ATS success rate` · `Submitted` · `Interview` · `Offer` · `Rejected` · `Withdrawn`

## How to Use

1. Add one row per application, in the order you apply.
2. Update **Status** and **Next Action** as things move.
3. Set a **Follow-up Date** so nothing slips through the cracks.
4. Move rows to the [Archive](#archive) section once they're fully closed (rejected, offer accepted/declined, withdrawn).
